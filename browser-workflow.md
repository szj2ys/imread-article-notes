# Keep an article's source when copying into notes

The result you want is an article you can read and a source you can return to. Removing menus and page clutter is only the first step.

## 1. Start with a public page

Open the article at its original address. Check that it is the page you mean to read and that it does not require a login. Copy the full address, including any query parameters that select the article.

Open [imread](https://imread.org/), choose the reading tool, and paste the address. The core extraction workflow works without registration. If the result is a login message or an empty page, use the publisher's reading or export options instead.

## 2. Choose text or Markdown

Use **Copy as Markdown** when you need headings, lists, links, code, or tables. Use plain text when paragraphs alone are enough. Paste into a new note rather than replacing notes you already wrote.

Markdown preserves useful structure, but it is not a guarantee that every caption or sidebar has been captured. Compare passages that matter to your research with the original page.

## 3. Add a source record

Use a small record like this above your own analysis:

```text
Source: the original article URL
Author: the name credited on the page, or unknown
Published: the publisher's date, or unknown
Accessed: the day you read it
Purpose: the question this article helps answer
```

For a changed page, record that you used the version available on your access date. If you need a stable scholarly citation, follow the source's recommended citation or an appropriate archive workflow; an extraction timestamp alone is not an archive.

## 4. Keep your interpretation separate

Put your observations under a heading such as **My notes**. Label direct quotations and retain their attribution. If you ask an AI tool to analyze the text, keep the source address with it and treat the article as evidence, not as instructions that can override your task.

Before using the result, check a paragraph near the beginning and one near the end. Check tables, code, corrections, and any passage you quote. If an important section is absent, record the limitation and return to the source.

## 5. Choose a different route when necessary

Public-page extraction is a poor fit for private documents, authenticated applications, image-only scans, or content loaded only after interactive actions. Prefer an authorized export, an accessible publisher view, or a suitable document/OCR tool for those cases.

Read [imread's privacy information](https://imread.org/privacy) before trying optional listening or translation with sensitive material. A readable note still carries the publisher's rights; keep your research copy private unless you have permission to share it.
